# Module 01: Python & Data Science Fundamentals

Beginner practice notebook covering core Python building blocks for data analysis and data science workflows.

## What's Covered
- **Variables & Data Types:** Working with strings, integers, floats, and booleans (`str`, `int`, `float`, `bool`).
- **Lists & Dictionaries:** Structuring sample order records using a list of dictionaries.
- **Loops & Functions:** Calculating total sales and average order value, plus filtering high-value orders (`>= 1000`).
- **File Handling:** Writing a summary report to `module1_summary.txt` and reading it back.
- **Data Science Mini-Application:** Aggregating total sales by product category.

## How to Run
Open the `.ipynb` notebook in **JupyterLite**, **Jupyter Notebook**, or **Google Colab** and run the cells sequentially from top to bottom.
